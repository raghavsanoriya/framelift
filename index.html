    Privacy

    Your video never leaves this device. Decoding, frame extraction and the AI model all run inside this browser tab. Only the app files and the AI model weights are downloaded from a public CDN; nothing is sent back.

    About AI upscaling

    The AI model adds believable detail when it enlarges an image. It can’t recover detail the camera never captured, so check faces, small text and logos closely.

    Speed tips

    Keep this tab open and visible while converting, because browsers slow down background tabs. On laptops with two graphics cards, set your browser to “High performance” in Windows Settings → System → Display → Graphics. HD 2× with the Standard model is the fastest good option; 4× and Best detail take much longer. The first run downloads the AI engine (about 30 MB) once.
